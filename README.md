# Graduation-Project
UI/UX design project for a [Travel App] created using Figma as part of the DEPI graduation project.
# 📎 Project Name : Travel & Toursim App
## 📌 Project Overview :
> 
> Egypt Travel is a travel discovery and booking platform designed to help users explore Egypt, discover destinations and attractions based on their interests, plan personalized trips, and book travel services.

### 📎🎓 Instructor : Hossam Elgazzar

### 🎯 Project Objectives : 
> 
> The goal of the project is to make discovering and planning a trip to Egypt easier, more personalized, and more engaging, while helping the tourism company convert users from browsing to booking.
---
### 📦 Project Scope :
> We will design a platform that helps users discover tourist destinations, plan their trips, book activities and accommodations, and save their trips.
>
> The app brings essential travel information together in one place. Users can:
Discover the destination → Explore attractions → View hotels → Discover activities → Choose a travel package → Book with the tourism company.
> 
> Goal:
To create a simple and user-friendly travel platform that makes discovering destinations and planning trips easier, faster, and more organized.
> 
> Target Users:
Solo travelers
Couples
Families
Young travelers
People planning domestic or international trips
---
> 📅 Project Plan (5 Weeks) :-
> 
> Week 1 — UX Research & Planning
Conduct UX research, user interviews, and competitor analysis; define user needs, explore solutions, prioritize features, and develop user flows.
> 
> Week 2 — Low-Fidelity & Mid-Fidelity Wireframes
Create and refine low-fidelity and mid-fidelity wireframes for the main screens and user journeys.
> 
> Week 3 — Design System & High-Fidelity Design
Build the design system, including colors, typography, and reusable components, and begin high-fidelity screen designs.
> 
> Week 4 — High-Fidelity Design & Prototyping
Complete the high-fidelity screens, review visual consistency, and connect the screens into an interactive prototype.
> 
> Week 5 — Usability Testing & Refinement
Test key use cases with representative users, document findings, refine the prototype, and prepare the final presentation.
>
